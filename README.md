# Description du projet

AfriConnect Summit 2026 est un site web responsive conçu pour présenter une conférence africaine dédiée aux nouvelles technologies, à l'innovation et à l'entrepreneuriat numérique.

Le site permet aux visiteurs de découvrir les informations principales de l'événement, le programme des conférences, les intervenants, ainsi qu'un formulaire de contact.

Le projet a été développé uniquement avec les technologies demandées dans le cadre de l'examen, sans utiliser de framework JavaScript ni de framework CSS.

# Fonctionnalités JavaScript implémentées

- Compte à rebours (Countdown) jusqu'à l'événement
- Animation des compteurs statistiques
- Animations au défilement avec Intersection Observer
- Navigation dynamique entre les jours du programme
- Filtrage des intervenants par catégorie
- Validation du formulaire de contact
- Bouton "Retour en haut"
- Changement automatique de l'année dans le footer
- Thème sombre (Dark Mode)
- Sauvegarde du thème avec LocalStorage
- Navigation dynamique lors du défilement de la page
